## Как работаем
- **Gemini** (`agy`, режим `accept-edits`) правит код по заданию, которое пишет Claude Code: одна задача — один прогон, файлы пересекаются → задачи идут по очереди.
- **Claude Code** пишет задания, проверяет каждый diff, собирает и тестирует, при ошибках возвращает Gemini на доработку.
- **Пользователь** принимает решения (помечены 🟡) и делает всё во внешних сервисах (помечены 🔑): Heroku, Supabase, Firebase, App Store Connect.
- **Проверка после каждой фазы:**
  - Android — `assembleDebug` + `testDebugUnitTest` (сейчас 108 тестов) + скриншоты на эмуляторе;
  - iOS — push в ветку → GitHub Actions собирает, гоняет тесты, делает скриншот;
  - бэкенд — `go build ./...` + `go test` (middleware/service).
- **Коммиты** — в отдельную ветку на фазу, по коммиту на задачу. **Push в `main` с изменениями `backend/` = деплой на Heroku → только после твоего «да».**
- Паритет: если задача есть на обеих платформах — делаем на обеих в одной фазе.
